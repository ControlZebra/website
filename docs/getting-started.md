# Getting Started

This guide gets you from install to first successful save.

## 1) Install ControlZebra

1. Download the latest desktop build from your team release channel.
2. Run the installer.
3. Open ControlZebra.

Add direct public download links for Windows and macOS release channels.
:::

## 2) First-time setup

When you launch ControlZebra for the first time:

1. Open **Settings**.
2. Set your profile identity (name and email) so saved history is labeled correctly.
3. Connect your account provider (GitHub or GitLab) if your team uses cloud sync.

:::tip
If you are not sure which account to connect, ask your team lead before continuing.
:::

## 3) Open your project folder

1. Click **File → Open Folder**.
2. Select your project directory.
3. ControlZebra checks whether the folder is already version-tracked.

- If it is already tracked: you can start working immediately.
- If it is not tracked: ControlZebra prompts you to start tracking it.

## 4) Create your first safe checkpoint

1. Make a small test edit (for example, update a note file).
2. Open **Changes** and review what changed.
3. Click **Save Changes** and add a short summary.
4. Click **Share** (if your project is connected to a remote team workspace).

## 5) Start a new project (recommended flow)

Use this when your folder is not version-tracked yet:

1. Create or choose a local project folder.
2. Open it in ControlZebra.
3. Start version tracking when prompted.
4. Save your first checkpoint.
5. Connect a remote location (if your team shares this project).
6. Share your first checkpoint.

## 6) Daily startup checklist

- Open the right folder
- Click **Sync**
- Confirm there are no unresolved conflicts
- Start your work
